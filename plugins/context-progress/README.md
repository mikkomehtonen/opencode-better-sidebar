# @streetturtle/opencode-context-progress

OpenCode sidebar plugin that replaces context text with a compact progress view.

- Line 1: context progress bar + percent used
- Line 2: consumed tokens / context window / spent cost

## Install

```sh
opencode plugin @streetturtle/opencode-context-progress
```

Global install:

```sh
opencode plugin --global @streetturtle/opencode-context-progress
```
